# S03 팁 등록 화면명세

문서 정보: 버전 v01 · 2026-10-20 · 내 시안 반영(ICN Subway Steps) · 작성 Claude Code, 검토자: (본인 이름)

사용한 시안 파일: docs/screens/ICN-subway-steps-v01.html (S03 부분). 실제 서버·Flutter 실행 결과가 아닙니다.
관련 요구사항: R04 팁 등록 · R05 로그인 (docs/ui-requirements.csv)

| 항목 | 내용 |
| --- | --- |
| screenId | S03 |
| title | 팁 등록 (EN: Add a tip) |
| purpose | 로그인한 사용자가 S02에서 보던 단계에, 다른 여행객에게 도움이 될 팁(예: 짐이 많을 때 쓸 엘리베이터 위치)을 남긴다. |
| entryCondition | S02의 '+ 팁 등록'을 누른다. 로그인하지 않았다면 S04를 거친 뒤 같은 단계 정보를 가지고 돌아온다. 어떤 경로·몇 단계에서 들어왔는지가 반드시 함께 넘어온다. |
| elements | 단계: 읽기 전용 한 줄(예: 직통열차 · 3단계 — 직통열차 승차권 사기). 팁 제목: 한 줄 입력·필수, 오른쪽 아래 글자 수 n/80. 정확한 위치: 한 줄 입력·필수, n/80. 메모: 여러 줄 입력·선택, n/150. 사진: 파일 선택·선택 항목(시안에만 있음, openQuestions 참고). 팁 올리기: 주요 버튼(남색). 취소: 보조 버튼. |
| action | 팁 올리기는 입력을 확인한 뒤 '올리는 중…'으로 바뀌고 반복해서 누르지 못한다. 성공을 확인하면 S02의 같은 단계로 돌아가 '팁을 올렸습니다' 알림을 띄우고, 새 팁은 '확인됨' 상태·'내가 올림'으로 보인다. 실패하면 작성한 값을 유지하고 다시 시도를 둔다. 취소는 S02의 같은 단계로 돌아간다. |
| validation | 팁 제목과 정확한 위치는 앞뒤 공백을 제거한 뒤 1~80자. 메모는 선택이며 최대 150자. 비었거나 길면 각 칸 아래에 안내한다: 비었을 때 "1~80자로 입력하세요.", 80자 초과 "80자 이하로 입력하세요.", 메모 150자 초과 "150자 이하로 입력하세요."(영어 화면은 같은 뜻의 영어 문구). 칸을 고치기 시작하면 그 칸의 오류만 지운다. 단계·상태·올린 사람은 화면에서 입력받지 않는다. |
| states | 기본: 단계만 채워진 빈 입력. 입력 오류: 해당 칸 테두리·문구 빨강, 다른 값 유지. 올리는 중: 주요 버튼 비활성·'올리는 중…'. 올리기 실패: 값 유지와 다시 시도 안내. 성공: S02 같은 단계로 이동 후 알림. |
| navigation | S02 → S03 또는 S02 → S04 → S03. 성공·취소·뒤로 가기는 S02 같은 단계로 이동한다. 입력 오류와 올리기 실패는 S03에 머문다. |
| openQuestions | 1) 사진 첨부는 시안에만 있다. 교재 7장 기본 범위에는 사진이 없고 P08 선택 확장이므로, 기본 구현에서 뺄지 P08로 넣을지 결정 필요. 2) 작성 중 취소할 때 확인창을 띄울지, 작성 내용을 복원할지 미정(시안은 확인 없이 돌아가며 복원하지 않음 — 결정이 아니라 시안의 단순화). 3) 같은 단계에 같은 내용의 팁이 이미 있을 때 막을지 미정. 4) 로그인 세션이 만료된 상태에서 팁 올리기를 누르면 S04로 보낼 때 작성 중 값을 지킬지 미정. |

그림에서 확인한 것: 단계 읽기 전용 칸, 세 입력칸과 글자 수, 칸별 오류 문구, 올리는 중 상태, 성공 뒤 S02 복귀와 알림(시안 동작 기준).
별도로 전달받은 규칙: 제목·위치 1~80자, 메모 150자, 로그인 후 원래 단계로 복귀, 상태는 올린 사람만 변경.
확인하지 못한 것: 실제 서버 응답과 오류 형식, Flutter 키보드가 올라왔을 때 버튼 위치, 글자 확대 시 줄바꿈.

공통 모양은 design-system.json과 component-rules.md를 함께 읽습니다.

# S03 물건 등록 화면명세

문서 정보: 버전 v02 · 2026-10-05 · 제공 작성 예

제공 시안의 작성 예입니다. 자기 시안과 확정한 결정으로 수정해 사용합니다. 실제 서버·Flutter 실행 결과가 아닙니다.


| 항목 | 내용 |
| --- | --- |
| screenId | S03 |
| title | 물건 등록 |
| purpose | 로그인한 학생이 주운 물건의 정보를 작성한다. |
| entryCondition | S01에서 물건 등록을 선택한다. 로그인하지 않았다면 S04를 거친 뒤 돌아온다. |
| elements | 물건 이름: 한 줄 입력·필수. 발견 장소: 한 줄 입력·필수. 메모: 여러 줄 입력·선택. 등록하기: 주요 버튼. 취소: 보조 버튼. 기본 범위에는 사진 첨부가 없다. |
| action | 등록하기는 입력을 확인한 뒤 진행 상태를 표시한다. 진행 중에는 같은 등록을 반복해서 누르지 못하게 한다. 성공을 확인하면 완료 안내 뒤 S01로 이동한다. 실패하면 작성한 값을 유지한다. |
| validation | 이름과 발견 장소는 앞뒤 공백을 제거한 뒤 1~80자. 메모는 선택이며 최대 150자. 이름 누락은 “물건 이름을 입력해 주세요.”, 장소 누락은 “발견 장소를 입력해 주세요.”로 각 항목 아래에 안내한다. |
| states | 기본: 입력 전. 입력 오류: 해당 칸에 문구 표시. 등록 중: 진행 안내. 등록 실패: 값 유지와 다시 시도 안내. 성공: 완료 안내 후 목록 이동. |
| navigation | S01 → S03 또는 S01 → S04 → S03. 등록 성공과 취소는 S01로 이동한다. 입력 오류와 등록 실패는 S03에 머문다. |
| openQuestions | 작성 중 취소할 때 확인창을 띄울지, 임시로 작성한 내용을 다시 열면 복원할지는 미정이다. 실제 구현 제약을 확인한 뒤 결정한다. |


공통 모양은 design-system.json과 component-rules.md를 함께 읽습니다.

그림에서 확인한 것: 진행 표시·사진·표지판 칩·안내·버튼·팁 카드 배치, 상태 배지 두 가지, 사진 준비 중 자리표시, 언어 전환 동작(시안 동작 기준).
별도로 전달받은 규칙: 등록자만 상태 변경, 로그인 후 원래 단계로 복귀, 사진은 licenses.txt의 출처 표기 유지.
확인하지 못한 것: 실제 서버 응답, Flutter 실행 화면, 실제 역 구조와 표지판 문구의 정확한 위치.

공통 모양은 design-system.json과 component-rules.md를 함께 읽습니다.

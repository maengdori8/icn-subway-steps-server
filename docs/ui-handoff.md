- 안내 종료점은 공항철도 탑승. 마지막 버튼 '승강장에 왔어요', 완료 화면은 승차권 보관 한 줄 + 'n단계 다시 보기' + '경로 목록으로'.
- 테마(시스템·밝게·어둡게)와 언어(English·한국어)는 S05 설정에서만 바꾼다. 지구본 버튼은 어디에도 없다. 영어가 기본이고 둘 다 기기에 기억한다.
- 하단 메뉴(경로 S01 / 내 팁 S06 / 설정 S05)는 최상위 화면에만. S02~S04·S07에는 없다. 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 화면 아래 떠 있는 둥근 캡슐(아이콘 + 작은 글자)이고, 다른 탭을 고르면 연한 회색 선택 칸이 늘어나며 그 탭으로 미끄러진다. 캡슐 위를 끌면 칸이 손가락을 따라가고 놓은 자리의 탭으로 바뀐다. 누를 때 물결·눌림 색은 없다(2026-10-22 사용자 요청 D14·D15).
- 상단 바: 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 화면 바탕과 같은 색에 굵은 제목 가운데, 그림자 없음. 남색은 표지판 칩에만 쓴다(D14).
- S02 사진 넘김: 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 밀거나 이전·다음으로 넘길 때 인스타그램 스토리처럼 정육면체로 돌며 넘어간다. 동작 줄이기면 평평하게(D16).

## 화면 항목과 데이터 이름(서버 api-spec.yaml, camelCase)

| 화면 항목 | 데이터 이름 | 규칙 |
| --- | --- | --- |
| 경로 코드 | Route.code / Tip.route | EXPRESS · LOCAL · T2(준비 중). 팁은 EXPRESS · LOCAL만 |
| 경로 이름·한 줄 설명 | Route.name{en, ko}, Route.summary{en, ko} | 두 언어를 함께 받아 앱 언어로 보임 |
| 준비 중 여부 | Route.available | false면 '준비 중' 배지, 누르면 안내만 |
| 단계 수 | Route.stepCount | 진행 표시 '/N', 카드 'N 단계' |
| 단계 번호 | Step.stepNo / Tip.stepNo | 1부터 그 경로의 stepCount까지. S02에서 넘어옴 |
| 역할 라벨 | Step.role | HERE = 현재 위치, FIND = 이 표지판을 찾으세요 |
| 표지판 픽토그램 | Step.icon | PLANE · ESCALATOR · TRAIN |
| 단계 사진 | Step.photoKey | 앱에 든 사진 키. null이면 '사진 준비 중' |
| 표지판 글자 | Step.sign{ko, en} | 언어와 관계없이 병기 |
| 단계 제목·안내 줄 | Step.title{en, ko}, Step.instructions{en[], ko[]} | '{ko\|…}'는 다른 언어로 읽을 구절 |
| 엘리베이터 | Step.elevator{en, ko} | null이면 '엘리베이터: 현장 확인 중' |
| 팁 번호 | Tip.id | 서버가 정함 |
| 팁 제목 | Tip.title | 필수, 앞뒤 공백 제거 후 1~80 코드 포인트 |
| 정확한 위치 | Tip.location | 필수, 앞뒤 공백 제거 후 1~80 코드 포인트 |

| 상태 | Tip.status | VERIFIED = 작성자 확인, OUTDATED = 작성자가 오래됨 표시. 등록 때 서버가 VERIFIED |
| 배지 날짜 | Tip.verifiedAt | UTC 시각. 앱은 서울 날짜(YYYY-MM-DD)만 보임 |
| 올린 시각 | Tip.createdAt | UTC 시각(화면에 보이지 않음) |
| 올린 사람 | Tip.ownerId | 서버가 토큰으로 정함. 화면에서 입력받지 않음 |
| 내가 올림 | Tip.mine | 요청 토큰의 사용자가 올렸는지. 토큰이 없으면 false |

공통 규칙(서버 계약): 공개 GET에 무효·만료 토큰이 붙으면 401이다. 오류 본문은 {code, message, errors}이고 message는 한국어뿐이라 화면 문구는 앱이 고른다. 실패가 겹치면 401 → 400 → 404 → 403 순으로 판단한다.

시간 초과(현재 동작, 10장): 모든 요청은 15초가 지나면 끝낸다(HttpApiTransport). 읽기는 원인 모를 실패 + 다시 시도, S04는 '로그인하지 못했어요'. S03은 서버에 저장됐을 수 있어 바로 다시 보내지 않고 노란 상자 '올라갔는지 알 수 없어요' + [팁 목록 확인]을 보인다. 같은 팁이 있으면 S02로 돌아가 '같은 팁이 이미 있어요'를 알리고, 없으면 올리기 실패 상자(다시 시도). 불러오는 중 화면(S01, S02 단계·팁, S06)은 8초가 지나도 응답이 없으면 'Slow connection. Check the airport Wi-Fi. / 연결이 느려요. 공항 와이파이를 확인하세요.' 한 줄을 더한다(고도화 P03에서 넣음, 위젯 검사 통과·화면 대조 전).

## 다음 단계에 전달할 것

- 7장(서버): 이미 docs/requirements.md(R01~R08), functional-spec.md, api-spec.yaml에 옮겼다. 이 문서와 계약이 다르면 api-spec.yaml이 맞다.
- 9장(앱): 화면 구현은 끝났다. 이 문서 묶음에서 '규칙(앱 반영 필요)'이던 항목은 앱 고도화(P02~P04)에서 넣었다(위젯 검사 통과·화면 대조 전, 앱 reports/upgrade-log.md). 남은 권장·선택 묶음은 마감(10-22) 뒤에 정한다.
- 10장(연결): 끝남. HttpApiTransport가 15초 시간 초과를 넣고, 시간 초과는 원인 모를 실패로 보인다(S03만 결과 확인 흐름). offline('인터넷에 연결되지 않았습니다')은 기기에 망이 없다고 확인될 때(ENETDOWN·ENETUNREACH)만 쓰고, 서버가 꺼졌거나 연결을 거부하는 등 그 밖의 연결 실패는 원인 모를 실패다(앱 reports/app-integration.md).

9장의 가짜 저장소 화면과 10장의 실제 서버 연결을 구분한다. 시안의 로그인·팁 저장 동작은 실제 인증·저장 성공의 증거가 아니다. 실제 실행을 확인한 플랫폼·화면·행동과 미확인 범위는 앱 docs/handoff.md에 따로 적는다.

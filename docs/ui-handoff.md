## 확정한 것

- 네 화면: S01 경로 목록, S02 단계 안내, S03 팁 등록, S04 로그인. S01·S02는 로그인 없이 본다.
- 경로: T1 입국장 → 서울역 직통열차 5단계, 일반열차 5단계. T2는 '준비 중'으로 보이고 누르면 안내만 띄운다.
- 언어: 영어 기본, 한국어 전환. 표지판 글자(예: 직통열차 Express Train)는 언어와 관계없이 두 언어 병기.
- 팁은 S02의 특정 단계에 붙는다. 로그인한 사용자 누구나 올리고, 상태(확인됨·정보 오래됨)는 올린 사람만 바꾼다.
- 팁 입력: 제목·위치는 앞뒤 공백 제거 후 1~80자, 메모는 선택 150자. 실패 시 값 유지, 올리는 중 중복 누름 방지, 성공 시 S02 같은 단계로 복귀.
- 로그인 후에는 들어오기 전의 같은 단계(S03)로 돌아오고, S03·S04의 취소는 S02 같은 단계로 간다.
- 색: 남색 #12305F(바·주요 버튼), 직통 #B35300, 일반 #0B6FA8, 본문 #101B2E, 보조 글자 #4A5874, 입력칸 테두리 #6E7C97. 모두 WCAG 대비 기준을 계산해 확인함(design-system.json evidence 참고).

## 화면 항목과 데이터 이름(7장 데이터 모델의 입력)

화면에 보이는 항목을 수업 서버의 이름과 최대한 같은 후보로 연결했습니다. 실제 이름·길이는 7장에서 docs/data-model.md로 확정합니다.

| 화면 항목 | 데이터 이름 후보 | 규칙 |
| --- | --- | --- |
| 팁 번호 | id | 서버가 정함. 사용자가 입력하지 않음 |
| 경로 | route (EXPRESS / LOCAL) | S02에서 넘어옴. 화면에서 입력받지 않음 |
| 단계 번호 | step_no | 1부터 그 경로의 단계 수까지. S02에서 넘어옴 |
| 팁 제목 | title | 필수, 앞뒤 공백 제거 후 1~80자 |
| 정확한 위치 | location | 필수, 앞뒤 공백 제거 후 1~80자 |
| 메모 | note | 선택, 최대 150자, 빈 값은 null |
| 상태(확인됨 / 정보 오래됨) | status (VERIFIED / OUTDATED) | 등록할 때 서버가 VERIFIED로 정함. 올린 사용자만 바꿈 |
| 올린 사람 | owner_id | 로그인한 사용자. 화면에서 입력받지 않음 |

## 화면별 API 요구 목록

요청 경로는 후보이며, 7장 P01에서 docs/api-spec.yaml로 확정합니다. 확정한 계약이 이 표와 다르면 그 이유를 이 문서에 덧붙입니다.

| 화면ID | 사용자 행동 | 필요한 요청 후보 | 보내는 값 | 받는 값 | 로그인 필요 | 실패 시 화면 상태 |
| --- | --- | --- | --- | --- | --- | --- |
| S01 | 경로 목록 보기 | (미정) 앱 고정 또는 GET /api/routes | 없음 | 경로 목록(이름·단계 수·준비 중 여부) | 아니요 | 불러오는 중 → 0건이면 빈 목록, 연결 끊김이면 오프라인 안내와 다시 시도 |
| S02 | 단계의 팁 보기 | GET /api/tips?route={route}&step={step_no} | 경로·단계 번호 | 팁 목록(번호·제목·위치·상태·내가 올린 팁인지) | 아니요 | 팁 영역만 '불러오지 못함'과 다시 시도, 단계 안내는 그대로 |
| S02 | 팁 상태 바꾸기 | PATCH /api/tips/{id}/status | 팁 번호, 새 상태 | 바뀐 팁 정보 | 예(올린 사람만) | 로그인 전이면 S04 → S02 복귀, 다른 사람이면 거부 안내, 처리 실패면 상태 유지와 다시 시도 |
| S03 | 팁 올리기 | POST /api/tips | 경로·단계 번호·제목·위치·메모(상태·올린 사람은 보내지 않음) | 새 팁 번호 | 예 | 입력 오류면 칸 아래 문구와 값 유지, 처리 실패면 값 유지와 다시 시도, 로그인이 끝났으면 S04 |
| S04 | 로그인 | POST /api/auth/login | 사용자 이름·비밀번호 | 로그인 확인 값·사용자 이름 | 해당 없음 | S04에 머물며 입력 확인 안내 |

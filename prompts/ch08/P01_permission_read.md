# P01 권한 구조 확인(읽기만)

권한 모드: Plan(계획 모드, 소스 편집 없음)
사용법: '## 요청' 아래 줄을 Claude Code 입력창에 그대로 붙여 넣는다. 또는 이 파일을 내 서버 프로젝트의 prompts\ch08\ 에 복사하고 입력창에 `@prompts/ch08/P01_permission_read.md 의 요청을 수행해 줘`라고 입력한다.
경로가 다른 자기 프로젝트는 요청의 @경로를 실제 파일 경로로 바꾼 뒤 쓴다. 다른 프로젝트나 배포 원본을 덮어쓰지 않는다.

## 요청
@docs/api-spec.yaml @docs/auth-design.md
@docs/permission-matrix.md 를 읽어 줘.
지금은 파일을 수정하지 마.
수정·반환·삭제·파일 접근에서 인증과 등록자 검사가
어떤 파일과 함수로 이어지는지 표로 정리해 줘.
명세와 다른 곳은 근거 줄과 영향을 받는 요청을 적고,
가장 작은 수정 계획과 확인할 테스트를 제안해 줘.

읽는 파일: docs/api-spec.yaml, docs/auth-design.md, docs/permission-matrix.md, 관련 src

주로 바뀔 파일(예시): 없음(채팅의 표로 받는다)
목록 밖의 파일을 만들거나 바꿔야 하면 Claude Code가 먼저 이유를 말해야 한다. 파일 이름은 AI마다 다를 수 있으며, 명세·권한·실제 실행 결과가 기준이다.

확인과 기록: 명세와 다른 권한 조건이 있으면 표의 행과 원인 파일을 표시한다. P02 요청 1의 상태 점검도 읽고, 요청 2에서 권한 또는 상태 항목 중 이번에 고칠 하나를 지정한다. 차이가 없으면 3절의 Postman 검사로 넘어간다.
